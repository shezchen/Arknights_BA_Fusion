# 第二章：学园迷雾

## 2.3 首次正式会面

两界交汇处的缓冲地带，一片废弃的集装箱码头。

海风带着咸腥味吹过，卷起地上的砂砾。这里是空间扭曲最严重的区域之一，天空呈现出一种诡异的紫红色，仿佛是被撕裂的伤口。

两支队伍在相距五十米的地方停下了脚步。

一边是身着基沃托斯各色校服的少女们早濑优香站在最前方，身后是兴奋地东张西沃的才羽桃井和紧张的才羽绿。而在暗处，若干个红外瞄准点若隐若现，那是风纪委员会的狙击手。

另一边，则是全副武装的罗德岛小队。博士、阿米娅、凯尔希以及负责护卫的陈，所有人都穿着厚重的生化防护服，脸上戴着面具，哪怕是一寸皮肤都没有暴露在空气中。

"这看起来可不像是什么友好访问团。"优香皱起眉头，推了推眼镜，手中的双枪处于随时击发的状态，"这种封闭式的装束，通常只会出现在处理核泄漏或者极度危险品的时候。你们是在防备我们吗？"

"是为了保护你们。"

凯尔希向前半步，声音通过扩音器传出，经过电子处理后显得有些失真。她举起手中的一块数据板，上面显示着关于矿石病的科普图解。

"我们来自一个被'源石病'肆虐的世界。这种疾病通过体液和粉尘传播，而在我们体内，高密度的源石结晶时刻都在释放着感染源。如果不穿这身装备，我们呼出的每一口气，对你们来说可能都是致命的毒气。"

优香愣了一下。她设想过对方会很傲慢，或者很神秘，但没想过对方的第一句话是在担心传染给她们。她示意身后的绿用仪器扫描。

"能量读数确实很奇怪"绿看着平板电脑，小声说道，"那个叫凯尔希的人，体内有高密度的能量反应，但被那层防护服完美地隔绝了。如果那层防护服破裂周围环境的污染指数会瞬间爆表。"

"听起来像是某种自带诅咒的设定啊！"桃井忍不住插嘴，眼睛却盯着阿米娅看，"呐呐，那边那个戴着兔耳朵头盔的女生，你的耳朵是装饰品吗？还是真的会长在那里的？"

"桃井！现在不是问这个的时候！"优香喝止道。

阿米娅透过防护服的面罩看着她们。她能清晰地看到那些少女头顶漂浮的光环那是某种她从未见过的能量构造，纯净、稳定，与源石那种狂暴的能量截然不同。她很想问那是怎么回事，但她记得博士的嘱咐：专业，克制。

"我是罗德岛的领袖，阿米娅。"阿米娅的声音平静而有礼貌，"这是我的耳朵，我是卡特斯族。关于我们的身体构造以后可以详谈，现在更重要的是那个。"

她指向码头下方，那里有一条通往地底深处的巨大裂缝，正散发着肉眼可见的黑色雾气。

"不管是把你们拉过来的力量，还是我们正在追踪的异常，源头都在下面。"

"我们也是这么判断的。"优香收敛了情绪，恢复了理性的态度，"我们的探测器显示，下层区域出现了未知的空间反应。既然目标一致，我建议"

滴滴滴！！！

绿手中的探测器突然发出了尖锐的警报声。

"高能反应！"绿惊恐地喊道，"来自那个兔耳女生她的手腕！那种能量正在急速攀升，数值超过了安全阈值！"

气氛瞬间凝固。

优香几乎是本能地抬起双枪指向阿米娅："你在积蓄能量？是想攻击吗？！"

与此同时，陈手中的赤霄已经出鞘半寸，寒光凛冽，挡在了阿米娅身前："放下武器！"

远处，红色的激光点瞬间汇聚在阿米娅和陈的身上。风纪委员会的狙击手已经锁定了目标。

"误会！"阿米娅举起双手，但这个动作让优香更加紧张。

"不，这不是积蓄能量。"

一个沙哑的声音插了进来。博士越众而出，挡在了枪口和剑锋之间。他没有拿武器，只是平静地站在那里，这种反常的镇定让紧张的空气出现了一丝松动。

"阿米娅手上的指环，不是为了增幅力量，而是为了限制力量。"博士看着优香，"刚才的波动，是因为靠近那条裂缝，导致她体内的能量产生了共鸣，指环正在自动收紧以压制暴走。如果你仔细看数据，会发现能量并没有外泄。"

优香一怔，立刻看向绿。

绿满头大汗地操作着平板："确确实！虽然内部压力很大，但外部辐射值为零！那个指环是在是在把能量往里压！"

优香松了一口气，放下了枪口，额头上已经渗出了一层冷汗。"抱歉。作为队长，我必须对队员的安全负责。"

"理解。这是一个充满猜疑的开始。"博士点了点头，"但至少现在我们确认了两件事：第一，我们不想伤害你们；第二，下面那个东西，确实能引发我们双方力量的失控。"

陈冷哼一声，收剑回鞘。

"那么，暂时休战？"桃井探出头来，试图活跃气氛，"组队副本开启？"

阿米娅摘下面罩的一角只露出一双眼睛，那双深邃眼眸中带着真诚："是的。为了查明真相，罗德岛提议组建联合调查队。"

优香看着阿米娅那双清澈的眼睛，沉默了片刻，终于点了点头。

"同意。但我要走在前面。"优香重新检查了一下弹匣，"毕竟，如果是机械类的敌人，我的计算能力比你们的剑术更有用。"

虽然各自心存芥蒂，但在这个危机四伏的异世界路口，两支截然不同的队伍终于迈出了并肩同行的第一步。
